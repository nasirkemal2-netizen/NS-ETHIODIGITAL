# FutureProducts.md
Roadmap for NS-ETHIODIGITAL beyond the MVP (Minimum Viable Product)

## Planned Features Post-MVP
- Essay / Long-form question support with manual or AI-assisted grading
- Audio/Video question support for interactive assessments
- Proctoring features for secure online exams
- AI-driven analytics and personalized feedback for students
- Multi-language support for regional inclusivity
- Mobile-first enhancements for better UX on Android/iOS
- Integration with school management systems (SIS)
- Gamification features to increase student engagement

## Timeline & Milestones
- Q2 2030: Pilot additional question types (Essay, Audio/Video)
- Q3 2030: Launch AI analytics and feedback dashboard
- Q4 2030: Integrate proctoring and gamification features
- Q1 2031: Expand multi-language support and cross-platform optimizations
