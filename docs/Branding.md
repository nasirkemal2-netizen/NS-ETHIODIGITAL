# Branding.md
Color palette, fonts, and style guide for NS-ETHIODIGITAL

## Color Palette
- Primary: #1F2937 (Dark Gray)
- Secondary: #3B82F6 (Blue)
- Accent: #F59E0B (Yellow)
- Background: #FFFFFF (White)
- Text: #111827 (Dark Text)

## Fonts
- Primary font: Inter (Headings)
- Secondary font: Roboto (Body)

## Style Guide
- Buttons: Rounded corners (2xl), soft shadows
- Cards: Grid layout, adequate padding (p-2)
- Icons: Lucide-react
- Animations: Subtle, use Framer Motion
- Responsive: Mobile-first, supports web and mobile app
