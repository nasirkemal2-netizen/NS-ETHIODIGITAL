# STEP4_INTERACTIONS.md
Interactive elements, buttons, and form behaviors in NS-ETHIODIGITAL

## Overview
This file describes how users interact with the system through clickable buttons, input forms, dropdowns, checkboxes, and other interactive UI elements.

## Key Interactions

1. **Login / Registration Forms**
   - Email and password input
   - Submit button with validation
   - Forgot password / reset flow

2. **Exam Management (Teacher)**
   - Add / Remove questions from Item Bank
   - Publish / Unpublish Exams
   - Edit Exam details inline

3. **Student Exam Interface**
   - Navigate between questions (Next / Previous)
   - Select answer (radio button, checkbox)
   - Timer countdown and auto-submit

4. **Dashboards**
   - Clickable cards for results, exams, or users
   - Filters and search bars for easy navigation

5. **Notifications / Alerts**
   - Confirmation pop-ups
   - Success / Error messages
   - Optional toast notifications

## Notes
- Consistency in button style and placement is important
- Forms should provide immediate feedback on errors
- Interactive elements linked to navigation and user flow in STEP3
