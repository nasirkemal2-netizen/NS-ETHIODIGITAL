# STEP5_ACCESSIBILITY.md
Accessibility guidelines for NS-ETHIODIGITAL

## Overview
This file describes how the system ensures accessibility for all users, including those with disabilities.

## Guidelines

1. **Color & Contrast**
   - Ensure sufficient color contrast for text and backgrounds
   - Avoid relying on color alone to convey information

2. **Text & Fonts**
   - Use readable font sizes (minimum 14px for body text)
   - Support scalable text / zoom without breaking layout

3. **Keyboard Navigation**
   - All interactive elements accessible via keyboard
   - Logical tab order for forms and buttons

4. **Screen Readers**
   - Provide descriptive alt text for images
   - Labels for form inputs
   - ARIA roles for interactive elements

5. **Forms & Feedback**
   - Clear error messages
   - Instructions for required fields
   - Focus indicators for input fields

6. **Testing**
   - Regular accessibility audits
   - Test with real users with disabilities when possible

## Notes
- Accessibility should be considered in all screens (STEP2) and interactions (STEP4)
- Optional: WCAG 2.1 compliance checklist
