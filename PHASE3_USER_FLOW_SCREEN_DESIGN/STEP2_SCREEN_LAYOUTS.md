# STEP2_SCREEN_LAYOUTS.md
Screen wireframes and mockups for NS-ETHIODIGITAL

## Overview
This file contains the design concepts for each screen in the web and mobile app. Screens include Admin, Teacher, and Student dashboards, exam interfaces, item selection, and result views.

## Example Screens

1. **Admin Dashboard**
   - Schools overview
   - Teacher & Student management
   - Results summary

2. **Teacher Dashboard**
   - Exam creation form
   - Item selection from Item Bank
   - Exam list and results overview

3. **Student Dashboard**
   - Available exams list
   - Take exam interface (time countdown, question display)
   - View submitted responses and results

## Notes
- Wireframes can be hand-drawn or digital (Figma, Sketch, Adobe XD)
- Each screen linked to navigation flow in STEP3
- Include annotations for buttons, forms, and interactive elements
