# STEP3_NAVIGATION_FLOW.md
Navigation flow between screens in NS-ETHIODIGITAL

## Overview
This file describes how users move from one screen to another based on their role (Admin, Teacher, Student) and actions.

## 1. Admin Navigation
- Login → Admin Dashboard
- Admin Dashboard → Manage Schools → Add/Edit School
- Admin Dashboard → Manage Users → Add/Edit Teachers & Students
- Admin Dashboard → View Reports → Results / Audit Logs

## 2. Teacher Navigation
- Login → Teacher Dashboard
- Teacher Dashboard → Create Exam → Select Items → Publish
- Teacher Dashboard → View Exams → Edit / Delete
- Teacher Dashboard → View Results → Individual Student Scores

## 3. Student Navigation
- Login → Student Dashboard
- Student Dashboard → Available Exams → Start Exam
- Exam Screen → Navigate Questions → Submit
- Student Dashboard → View Results → Feedback / Scores

## Notes
- Navigation should be intuitive and consistent across web and mobile
- Use breadcrumbs, menus, and back buttons where necessary
- Link wireframes (STEP2) with navigation flow for clarity
