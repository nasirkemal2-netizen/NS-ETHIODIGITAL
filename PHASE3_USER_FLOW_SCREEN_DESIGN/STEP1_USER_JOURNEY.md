# STEP1_USER_JOURNEY.md
User journey mapping for NS-ETHIODIGITAL

## Overview
This file describes the journey of each user type (Admin, Teacher, Student) from login to completing their main tasks.

## 1. Admin Journey
1. Login → Dashboard
2. Create / Manage Schools
3. Assign Teachers and Students
4. View Results / Reports
5. Audit Logs / System Settings

## 2. Teacher Journey
1. Login → Dashboard
2. Create Exams
3. Select Items from Item Bank
4. Publish Exams for Students
5. View Student Results
6. Edit / Update Exams

## 3. Student Journey
1. Login → Dashboard
2. View Available Exams
3. Take Exams (time-limited)
4. Submit Responses
5. View Results / Feedback
