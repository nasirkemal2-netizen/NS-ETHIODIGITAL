# STEP5_BUG_TRACKING.md
Bug tracking for NS-ETHIODIGITAL

## Overview
This file records all issues, defects, and resolutions discovered during testing and pilot usage.

## Bug Reporting
- Each bug should include:
  - ID / Reference number
  - Date discovered
  - Module / Step affected
  - Severity (Critical, Major, Minor)
  - Description of the issue
  - Steps to reproduce

## Bug Resolution
- Document status: Open / In Progress / Resolved / Closed
- Include assigned developer or team member
- Resolution notes and final verification steps

## Notes
- Link related bugs to relevant test cases (STEP2–STEP4)
- Prioritize critical bugs for immediate fixes
- Maintain chronological log for transparency
- Optional: use GitHub Issues or Jira for tracking
