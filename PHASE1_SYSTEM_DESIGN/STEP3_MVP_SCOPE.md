# STEP3: MVP Scope

## MVP Version 1 Features
- Item Types:
  - Multiple Choice (MCQ)
  - True / False (TF)
  - Matching
- Auto grading for MCQ & TF
- Time-limited exams
- Result viewing & export (Excel / PDF)
- Multi-school supported
- Role-based access (Admin, Teacher, Student)

## Not Included in MVP
- Essay questions
- Audio / Video items
- Proctoring features
- AI-assisted marking
